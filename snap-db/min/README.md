# min

A web browser with smarter search, improved tab management, and built-in ad bl

Packaged by snapkit from the release asset `min-1.35.7-amd64.deb`,
tracked against [minbrowser/min](https://github.com/minbrowser/min).
This snap is not published or endorsed by the upstream project.

## Building

    cd /home/bearen/.local/share/snapkit/projects/min
    snapcraft

## Installing what you built

    sudo snap install --dangerous min_1.35.7_amd64.snap

## Updating

`snapkit` checks that upstream for a newer release and rewrites
`snap/snapcraft.yaml` for you. Anything you change in that file is kept:
an update only moves the version, the source URL and its checksum.
