# discord

Chat for Communities and Friends

Packaged from []() by snapkit, from the release asset
`discord-1.0.155.deb`. This snap is not published or endorsed by the upstream
project.

## Building

    cd /home/bearen/Development/snap/discord-snap
    snapcraft

## Installing what you built

    sudo snap install --dangerous discord_1.0.155_amd64.snap

## Updating

`snapkit` checks  for a newer release and rewrites
`snap/snapcraft.yaml` for you. Anything you change in that file is kept:
an update only moves the version, the source URL and its checksum.
