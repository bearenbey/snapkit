# pear

Pear 🍐 is extension for music player

Packaged by snapkit from the release asset `youtube-music_3.12.0_amd64.deb`,
tracked against [pear-devs/pear-desktop](https://github.com/pear-devs/pear-desktop).
This snap is not published or endorsed by the upstream project.

## Building

    cd /home/bearen/.local/share/snapkit/projects/pear
    snapcraft

## Installing what you built

    sudo snap install --dangerous pear_3.12.0_amd64.snap

## Updating

`snapkit` checks that upstream for a newer release and rewrites
`snap/snapcraft.yaml` for you. Anything you change in that file is kept:
an update only moves the version, the source URL and its checksum.
